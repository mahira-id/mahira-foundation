# Architecture Decision Records (ADR)

ADR menjelaskan keputusan arsitektural dengan konsekuensi lintas domain. Gunakan status `Proposed` sampai disetujui. Setiap ADR wajib menyebut keputusan register terkait.

## Format

- ID berurutan `ADR-NNNN`.
- Satu keputusan utama per ADR.
- Status: Proposed, Accepted, Rejected, Superseded.
- Catat konteks, opsi, keputusan, konsekuensi, bukti, dan trigger review.
- Jangan mengubah ADR Accepted; buat ADR pengganti.
