# References and Research Archive

Folder ini hanya berisi bahan referensi non-normatif: percakapan AI, perbandingan provider, catatan riset, screenshot, dan tautan eksternal. Isi referensi tidak otomatis menjadi keputusan atau spesifikasi.

Rules:
1. Preserve source title, author/tool, date captured, URL/source, and whether content was verified.
2. Add a short note explaining which decision or question the reference supports.
3. Mark time-sensitive prices, plan limits, compatibility claims, and legal statements with an observation date and re-verify before use.
4. When a reference leads to a decision, record the decision in `DECISIONS.md` and ADR; do not point developers to a conversation as the only authority.
5. Keep one canonical copy of duplicate research exports. Do not delete potentially useful originals until duplication is confirmed.

Suggested metadata header:

```yaml
reference_id: REF-001
title: Hosting comparison notes
source: Claude conversation export
captured_at: YYYY-MM-DD
status: non-normative
supports: DEC-008
verification_required: true
```
