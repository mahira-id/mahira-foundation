# Mahira Indonesia Development — Project Documentation

Dokumen konteks dan referensi utama pengembangan platform Mahira Indonesia Development (nama kerja).

## Dokumen

- [`PRD.md`](./PRD.md) — Product Requirements Document: visi produk, pengguna, ruang lingkup, kebutuhan, prioritas, dan kriteria penerimaan.
- [`PDD.md`](./PDD.md) — Product Design Document: arah visual, design system, prinsip editorial, layout, dan pengalaman pengguna.
- [`SRS.md`](./SRS.md) — Software Requirements Specification: persyaratan fungsional/nonfungsional, aktor, arsitektur target, keamanan, integrasi, dan pengujian.

## Urutan referensi

1. Gunakan PRD untuk memahami **apa** yang dibangun dan **mengapa**.
2. Gunakan PDD untuk memahami **bagaimana produk terlihat dan digunakan**.
3. Gunakan SRS untuk memahami **bagaimana sistem harus berperilaku dan diverifikasi**.

## Status dokumen

Ketiga dokumen merupakan baseline draft versi 0.1. Keputusan yang belum tervalidasi ditandai sebagai asumsi atau keputusan terbuka dan tidak boleh dianggap final sebelum disetujui pemilik produk/stakeholder.
